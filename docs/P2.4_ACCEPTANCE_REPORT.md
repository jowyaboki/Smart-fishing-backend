### 2. Numerical Integrity Findings & Remediations

| Component | Finding | Remediation Applied |
| :--- | :--- | :--- |
| **`validationStatistics.ts`** | `detectLocalExtrema()` did not validate individual points for valid ISO strings, `timeMs` coherence, or non-finite heights; duplicate timestamps were silently sorted. | Added strict per-point validation (`validateDiscretePoint()`), requiring valid ISO UTC strings ending in `Z`, finite `timeMs` coherent with ISO parsing, finite `heightMeters`, and duplicate timestamp detection throwing explicit errors. |
| **`validationStatistics.ts`** | `detectLocalExtrema()` validation order allowed short series (< 3 points) to return `[]` before validating malformed objects or non-finite values. | Reordered validation: every point is validated *before* checking dataset length. Short series with invalid inputs are rejected with descriptive errors. |
| **`validationStatistics.ts`** | Timestamp validation used naive `endsWith('Z')` and `Date.parse`, allowing impossible calendar dates (e.g. Feb 31, Month 13, Hour 25, Minute 60, non-leap Feb 29). | Implemented `isValidCalendarUtcIso()` using regex parsing and `new Date(0).setUTCFullYear(year, month - 1, day)` / `setUTCHours()` roundtrip verification. |
| **`validationStatistics.ts`** | `Date.UTC(year, ...)` constructor maps years 0–99 to 1900–1999, distorting valid historical dates. | Replaced `Date.UTC` with `new Date(0).setUTCFullYear()`, formally supporting ISO calendar years `0000` through `9999`. |
| **`validationStatistics.ts`** | `calculateStatisticalMetrics()` accepted non-array or non-finite float inputs without pre-validation; intermediate sums could overflow. | Added array check, per-pair finite float checks, intermediate overflow guards, variance non-negativity floor (`Math.max(0, variance)`), and post-rounding finite validation. |
| **`validationStatistics.ts`** | `calculatePeakValidationMetrics()` allowed negative, zero, non-finite, or unbounded `maxMatchingWindowMinutes`. | Enforced positive finite bound `0 < maxMatchingWindowMinutes <= 1440` (24h) and `0 < medianObsIntervalMinutes <= 1440`; guarded `maxWindowMs` calculation against overflow. |
| **`empiricalValidationService.ts`** | Prediction loop had no workload ceiling, enabling potential unbounded compute (Denial of Service). | Enforced `MAX_PREDICTION_POINTS = 50,000` limit, rejecting excessive workloads before peak provider calls; added start/end date ordering enforcement (`startMs <= endMs`). |
| **`empiricalValidationService.ts`** | Tide provider output was not checked before pushing to `independentPredictedPoints`. | Added immediate finite check on `pred?.currentTide?.heightMeters`, throwing or excluding gracefully upon non-finite provider responses. |
| **`empiricalValidationService.ts`** | Complex object serialization into SQLite could theoretically persist `NaN` or `Infinity`. | Added non-finite number checks before saving validation runs to the SQLite database. |
