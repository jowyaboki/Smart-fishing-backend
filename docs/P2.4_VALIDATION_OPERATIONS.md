# P2.4 Validation Operations Manual

## 1. Operating Procedures

This manual details how to execute, inspect, and monitor empirical tide validation runs via the Smart Fishing Backend API.

---

### 2.2 List Validation History
- **Route:** `GET /api/v1/hydrographic/stations/:stationId/validations?limit=20`
- **Response `200 OK`:**
  ```json
  {
    "count": 1,
    "stationId": "casablanca-port",
    "runs": [ ... ]
  }
  ```

### 2.3 Fetch Specific Run
- **Route:** `GET /api/v1/hydrographic/validations/:id`
- **Response `200 OK`:** Full `TideValidationRun` object.

---

## 3. Operational Policies

1. **Idempotent Ingestion & Validation:** Validation does not modify observations or station metadata; repeated validations produce independent historical records.
2. **Safeguard Inspection:** Always check `isCalibrationEnabled === false` and `status === 'NOT_VERIFIED'` unless physical telemetry has received accredited third-party certification.
