# P2.4 Data Suitability Criteria

## 1. Objective

Before any statistical metrics can be considered representative of astronomical model behavior, the underlying observational dataset must satisfy strict oceanographic suitability criteria.

The Empirical Tide Validation Engine automatically audits input data against these criteria and assigns a classification:
- `SUITABLE`
- `MARGINAL`
- `UNSUITABLE`

---

## 2. Suitability Evaluation Criteria

### 2.1 Sample Size and Temporal Duration
- **Full Calibration Threshold (`SUITABLE`):**
  - Minimum Observations: $\ge 720$ hourly observation pairs.
  - Minimum Timespan: $\ge 29.53$ consecutive days (one full synodic lunar month).
  - Completeness: $\ge 85\%$ expected temporal coverage.
  - Why: A complete synodic cycle covers spring-neap transitions (full moon, new moon, quadrature), lunar perigee-apogee fluctuations, and diurnal inequality.
- **Intermediate Threshold (`MARGINAL`):**
  - Minimum Observations: $\ge 100$ hourly pairs.
  - Minimum Timespan: $\ge 5$ consecutive days.
  - Evaluates short-term consistency but cannot validate long-period lunar constituents.
- **Deficient Data (`UNSUITABLE`):**
  - Observations $< 100$ or duration $< 5$ days.
  - Data is insufficient for statistical generalization.

### 2.2 Vertical Datum Integrity
- Station reference vertical datum (`LAT`, `CD`, `MSL`, `ZH`) must match observation datum exactly.
- If datum mismatch is detected, observation is rejected from validation pairs and logged in `exclusionReasons.datumMismatch`.

### 2.3 Physical Plausibility Limits
- Moroccan coastal waters exhibit tidal ranges from ~1.0m (Mediterranean) to ~4.0m (Atlantic).
- Allowable threshold bounds: $[-2.0\text{m}, +12.0\text{m}]$.
- Out-of-bounds readings are rejected (`exclusionReasons.outOfBoundsWaterLevel`).

### 2.4 Provenance Authenticity
- Provenance must specify:
  - `qualityTier === 'observed'`
  - `dataStatus === 'observation'`
  - `isSimulatedFallback === false`
- Simulated, estimated, or fallback series are rejected (`exclusionReasons.invalidProvenance`).

---

## 3. Decision Matrix

| Metric | Suitable | Marginal | Unsuitable |
| :--- | :--- | :--- | :--- |
| **Observation Count** | $\ge 720$ | $100 \le N < 720$ | $< 100$ |
| **Time Span (days)** | $\ge 29.53$ | $5 \le T < 29.53$ | $< 5$ |
| **Datum Validated** | Yes | Yes | No |
| **Provenance Validated** | 100% genuine | 100% genuine | Contains fake/simulated |
| **Calibration Permitted** | No (safeguard locked) | No | No |
